# 사이트 디자인 및 이벤트 기간 설정

관리자로 로그인하고 **관리자 → 사이트 디자인 / 이벤트 기간 설정**(`/admin/appearance`)으로 이동합니다.

1. 디자인을 **빼빼로데이**로 선택합니다.
2. **크림 라이트** 또는 **초콜릿 다크**를 고릅니다. 오른쪽 미리보기 또는 **크게 보기**로 저장 전 화면을 확인할 수 있습니다.
3. 시작 시각을 비워두면 저장 즉시 시작하고, 미래 시각을 입력하면 예약됩니다.
4. **종료 없이 계속 적용 (무기한)**을 선택하거나, 체크를 해제하고 종료 시각을 입력합니다. 예약 시작 후 무기한 적용도 가능합니다.
5. 떠다니는 효과를 선택하고 **설정 저장**을 누릅니다.

모든 입력 시각은 **한국 시간(KST, UTC+9)**이며 DB에는 UTC로 저장합니다.
시작 시각부터 적용하고 종료 시각부터 기본 디자인으로 돌아갑니다.
즉시 해제하려면 **기본 디자인**으로 저장합니다. 기존 예약도 함께 해제됩니다.
날짜는 일회성 예약이며 매년 자동 반복되지 않습니다.

## 적용 범위와 동작

- 기존 OJ 메뉴, 문제 풀이, 제출, 대회, 그룹 기능을 유지하면서 사이트 배경·색상과 메인 이벤트 소개 화면을 변경합니다.
- 시작/종료는 서버 시간을 기준으로 판단합니다. 별도 cron, 외부 예약 서비스 또는 워커 설정이 필요하지 않습니다.
- 이미 열린 페이지는 알려진 예약 시각에 새로고침 없이 디자인만 바뀝니다. 입력 중인 제출 코드가 초기화되지 않습니다.
- 관리자가 새로 저장한 변경은 새 페이지에는 즉시, 이미 열려 있는 페이지에는 최대 약 1분 이내 또는 탭 재진입 시 반영됩니다. 네트워크가 끊겨도 이미 받은 예약의 종료는 동작합니다.
- 미리보기는 관리자만 접근할 수 있고 설정을 저장하지 않습니다. 예시 문제 대신 실제 접근 가능한 OJ 콘텐츠를 표시합니다.
- OS의 ‘동작 줄이기’ 설정을 존중합니다. 장식은 클릭이나 스크린 리더 탐색을 막지 않습니다.

## 기존 서버 업데이트

병합 후 프로젝트 디렉터리에서:

```bash
git pull --ff-only
docker compose up -d --build web
```

`web` 서비스 시작 시 기존 스키마 관리 절차가 `site_appearance` 테이블을 자동 생성합니다.
기존 DB와 문제 파일은 그대로 사용하며 기본값은 **기본 디자인**입니다.
이벤트를 적용하려면 업데이트 후 관리자 설정에서 직접 선택하고 저장하세요.

전체 백업에는 디자인 설정도 포함됩니다. 이 기능이 추가되기 전 백업도 복구할 수 있으며, 해당 백업에 설정이 없으면 기본 디자인으로 복귀합니다.

## 검증

```bash
python -m pytest -q
node --test tests/site_appearance_browser.test.cjs
```

예약 경계(KST/UTC), 무기한, 관리자 권한, CSRF, 미리보기 격리, 잘못된 기간, DB 저장, 백업 호환성 및 열린 페이지의 시작/종료 전환을 검사합니다.
