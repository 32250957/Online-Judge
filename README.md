# 온라인 저지 개발
이 프로젝트는 LLM(ChatGPT)으로 온라인 저지를 개발하는 프로젝트입니다.
개발자는 오로지 프롬프팅과 디버깅 4단계 중 1단계(문제 정의), 4단계(결과 검증)만 수행합니다.
코드 작성과 디버깅 2단계(원인 추적), 3단계(코드 수정)는 모두 LLM이 수행합니다.

해당 프로젝트의 모든 권리는 제가 가지고 있습니다.

## 이벤트 디자인

관리자 → **사이트 디자인 / 이벤트 기간 설정**에서 빼빼로데이 디자인을 적용할 수 있습니다.
한국 시간 기준 예약 시작, 자동 종료, 무기한 적용, 라이트·다크 색상 및 움직임 설정을 지원합니다.
설정 방법과 업데이트 안내는 [이벤트 디자인 가이드](docs/site-appearance.md)를 참고하세요.
